# โปรแกรมคำนวณภาษีเงินได้บุคคลธรรมดา (Java)

## รายละเอียดโปรเจกต์

โปรแกรมนี้เป็นโปรแกรมคำนวณภาษีเงินได้บุคคลธรรมดาของประเทศไทย พัฒนาด้วยภาษา Java แบบ Console Application

ผู้ใช้สามารถกรอกข้อมูลรายได้หลายประเภท และโปรแกรมจะคำนวณภาษีตามอัตราภาษีแบบขั้นบันได พร้อมแสดงสูตรการคำนวณและสรุปผลลัพธ์

---

# ความสามารถของโปรแกรม

* รับข้อมูลรายได้เงินเดือน
* รับข้อมูลรายได้ธุรกิจส่วนตัว
* รับข้อมูลรายได้จากอสังหาริมทรัพย์
* รับข้อมูลรายได้อื่น ๆ
* คำนวณรายได้รวม
* หักค่าลดหย่อนพื้นฐาน
* คำนวณภาษีแบบขั้นบันได
* แสดงสูตรการคำนวณภาษี
* แสดงผลสรุปรายได้และภาษี

---

# อัตราภาษีที่ใช้

| เงินได้สุทธิ (บาท)  | อัตราภาษี  |
| ------------------- | ---------- |
| 0 - 150,000         | ยกเว้นภาษี |
| 150,001 - 300,000   | 5%         |
| 300,001 - 500,000   | 10%        |
| 500,001 - 750,000   | 15%        |
| 750,001 - 1,000,000 | 20%        |
| มากกว่า 1,000,000   | 25%        |

# โปรแกรมที่ต้องใช้

* Java JDK 8 หรือใหม่กว่า

ตรวจสอบเวอร์ชัน Java:

```bash id="7wdd5o"
java -version
```

---

# วิธี Compile โปรแกรม

เปิด Terminal หรือ PowerShell ภายในโฟลเดอร์โปรเจกต์

จากนั้นใช้คำสั่ง:

```bash id="u0qnt6"
javac TaxCalculator.java
```

---

# วิธีรันโปรแกรม

ใช้คำสั่ง:

```bash id="q0ucjl"
java TaxCalculator
```
